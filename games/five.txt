<h2>Details</h2>
The game mostly involves purchasing three buildings, all named 5, to produce 5. There are six upgrades for each building, which all multiply that building's production by 2. Once 555555 fives have been produced, there is a chance for the big 5 button to give a 2. The game then continues the same, with 3 buildings and six upgrades each, but these instead produce the number 2.
